# Day 14 — Python and APIs

## Overview
This script connects to the free public **JSONPlaceholder Users API** to retrieve user profiles, process the JSON response, and display formatted information.

## API Endpoint
- **URL**: `https://jsonplaceholder.typicode.com/users`
- **Parameters**: `id` (searches by user ID)

## Extracted Information
- Full Name
- Username
- Email Address
- City
- Company NameD
